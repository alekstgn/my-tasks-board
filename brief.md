# Бриф: страница «Мои задачи»

## Цель
Локальная страница «Мои задачи» для персонального планирования: добавлять рабочие задачи, задавать приоритет и раскладывать задачу на шаги.

## Что должно быть (готовность)
- Добавление задачи: поле названия, выбор приоритета (высокий / средний / низкий), кнопка «Добавить».
- Список задач; у каждой карточки отображается приоритет.
- Данные хранятся в localStorage браузера и переживают перезагрузку.

## Правки, запланированные после базовой версии
- Правка 1: сортировка (высокий приоритет выше среднего, средний выше низкого; внутри приоритета новее выше); визуально выделяется только высокий приоритет.
- Правка 2: у задачи есть шаги; шаг добавляется по Enter; шаг можно отметить выполненным; прогресс «выполнено X из Y»; при пустых шагах — подсказка «Добавьте первый шаг».

## Границы
- Без сервера, авторизации, внешних библиотек и публикации.
- Один самодостаточный index.html.
- Не изменять brief.md в процессе работы.

## Готовность (приёмка)
- Страница открывается; обычное добавление задачи работает.
- Пустой список показывает спокойную подсказку.
- Пустое название не добавляет задачу; длинное название не ломает вёрстку.
- Ширины 390 px и 1440 px — вёрстка целая.
