# My Tasks Board

Локальный прототип «Мои задачи»: добавление задач с приоритетом, разбиение на шаги, прогресс выполнения. Одностраничный прототип без сборки и внешних зависимостей; данные — в localStorage браузера.

## Структура

- `brief.md` — бриф (требования и границы)
- `index.html` — прототип страницы
